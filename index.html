Cyberpunk 2077 Save Editor

CyberCAT-SimpleGUI Fork

I didn't start this one. Deweh wrote it in 2021 on top of CyberCAT, and seberoth kept it working through the 2.x patches until mid-2025. I really like it, but kept running into what it couldn't do - so I forked it and started filling in the gaps.

Now it opens saves from a browser, edits perks, cyberware and vehicles, backs up before it writes, and has tests and CI behind it.

Windows desktop · C# · .NET 10 · WinForms · v0.29
